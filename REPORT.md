## How to read this report

- **Ratio convention.** `% diff` is Rust relative to Go, computed as
  (Rust/Go − 1) × 100 on the median. For time, negative means Rust took
  less time. For throughput (rps), positive means Rust served more.
  Brackets give the 95% bootstrap CI.
- **Verdicts.** A verdict names a side only when all of these hold:
  - at least 5 independent process rounds per language;
  - the CI excludes 0;
  - Mann-Whitney p < 0.05;
  - the difference exceeds ±2%.

  Otherwise the verdict is "no measurable difference" or
  "insufficient rounds".
- **Three kinds of statement.** The discussion keeps apart:
  - **Measured**: what the tables show;
  - **Interpretation**: what the numbers imply for this workload;
  - **Possible explanation**: mechanisms that are consistent with the data
    but were not isolated by an experiment.
- **Scope.** Every statement applies to *these* programs, on *this*
  machine, with *these* toolchains and settings (METHODOLOGY.md). None is a
  general claim about either language.

## Limitations of this run

- **Shared VM.** This is a 4-vCPU cloud VM with no hardware performance
  counters and no CPU frequency control. The host's other tenants can steal
  CPU time; runs with more than 5% steal are flagged.
- **One machine for HTTP.** The HTTP load generator and the server share the
  machine, on disjoint cores. Runs where the load generator saturated are
  flagged and excluded.
- **No container results in this report.** Container results are reported
  separately (`make report MODE=container`) and are not part of this run.
